Closest approximation

20 steps · CFG 1 · shift 5 · simple · DPM++ 2M SDE · midpoint · eta 0 · s_noise 1 · CPU noise · denoise 1 · seed 12345 · add_noise true.

Upstream guide=0 conditional-only semantics map to CFG=1 here. The shift transform is equivalent; the compared 20-step sigma sequence matched. Solver equivalence was not established: first-sigma correction and integer vs floating timestep differences remain.

06 / REPRODUCTION & ARTIFACTS

A route back.
Not an exact replay.

モデル・環境・workflow templateを再構築するための記録です。完全再現は保証せず、非公開の素材やpromptは自分の入力に置き換えます。

  1. 01

    Recover the environment.

    Use the recorded ComfyUI commit and Python pins. Preserve the existing source and environment; nightly availability and a clean checkout are not guaranteed.

  2. 02

    Retrieve and verify the weights.

    Use the six-record model manifest for revision URLs, exact filenames, categories, bytes and SHA-256. Verify before loading, then place each file beneath models / its category.

  3. 03

    Prepare private inputs.

    Provide reference.png, driver.mp4, or pose-control.mp4 as required. v3 needs reference-aligned.png. Historical media and prompts remain private.

  4. 04

    Adapt the reference template.

    Replace CHARACTER_DESCRIPTION and any negative-prompt placeholder. Check host memory feasibility before a separately decided future test.

07 / LIMITS OF THE RECORD

What this test
cannot tell you.

確認できたのは短い生成の完走と、観測した失敗です。崩壊の原因や、別条件での品質・性能は未確認として分けて残します。

  • No long-video or multi-seed evidence.
  • No confirmed cause for v2 collapse or v3 degradation.
  • No peak memory, exclusive physical usage or per-stage timing.
  • No official exact upstream sampling reproduction.
  • No proof of native INT8 kernel arithmetic.
  • No guarantee of future nightly-package restoration.
  • No public rights decision for private inputs or generated media.
